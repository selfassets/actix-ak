# 宏观经济数据接口

提供中国核心宏观经济指标（GDP、CPI、PPI、PMI、LPR、社会融资规模、M2 货币供应量等）数据。

## 基础路径

`/api/v1/ak/macro`

---

## 1. 中国 GDP 增长数据

- **URL**: `/api/v1/ak/macro/china_gdp`
- **Method**: `GET`
- **Auth**: 需要 Bearer Token
